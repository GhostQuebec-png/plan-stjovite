CONFIGURATION

Première installation sur cet appareil

3 étapes — environ 3 minutes

Pour créer un token : github.com → photo de profil → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → coche uniquement la case gist → Generate. Copie le code « ghp_… » ici. Il reste enregistré sur cet appareil seulement.
Créer l'espace : à faire une seule fois, sur le premier appareil. Un identifiant d'espace te sera donné à transmettre à Damien avec le code d'accès.
